Suporte AltGrid

Respostas rápidas para instalação, login, sessões e desempenho.

Instalação no Windows

Baixe o instalador mais recente na página de downloads. Enquanto a certificação da Microsoft Store estiver em andamento, o Windows poderá exibir uma confirmação de segurança para instaladores baixados diretamente.

Instalação no Android

Baixe o APK oficial e autorize a instalação somente para o arquivo obtido pelo site do AltGrid. Não instale cópias compartilhadas por fontes desconhecidas.

Login com Google

Alguns jogos abrem o login em uma janela segura separada. Conclua a autenticação nessa janela e retorne à sessão original.

Desempenho

Ative o Eco Mode para reduzir FPS das sessões em segundo plano. Se um jogo apresentar falhas visuais, aumente o FPS daquela sessão ou desative temporariamente a economia.

Sessões e configurações

Fechar uma sessão não exclui sua configuração. Para remover permanentemente uma conta salva, use a opção “Excluir configuração” no menu da sessão.

Fale conosco

Envie sua dúvida, versão do aplicativo e uma captura do erro pelo Discord oficial do AltGrid. Nunca envie senhas ou tokens.

Antes de instalar

Avisos que podem aparecer em cada versão.

Essas mensagens são diferentes conforme o sistema. Só prossiga quando o download tiver sido iniciado pelos botões oficiais desta página.

WINDOWS · EXE

“O Windows protegeu o computador”

O SmartScreen pode mostrar “Editor desconhecido” enquanto o instalador direto constrói reputação e recebe assinatura.

  • Clique em Mais informações.
  • Confirme que o arquivo se chama AltGrid-Setup.
  • Use Executar assim mesmo somente se baixou por esta página.
  • Se a atualização interna não concluir, reinstale o Setup disponível nesta página; seus dados serão preservados.
O pedido de permissão do Windows para instalar também é esperado.
ANDROID · APK

“Instalação de fonte desconhecida”

Como o APK é distribuído diretamente, o Android ou o Play Protect pode pedir uma confirmação adicional.

  • Autorize temporariamente o navegador ou gerenciador de arquivos usado no download.
  • Continue somente com o APK oficial do AltGrid.
  • Se aparecer “App não instalado”, procure o suporte antes de remover uma versão anterior.
Desative novamente a permissão de fonte desconhecida após instalar.
MICROSOFT STORE

Produto ainda não disponível

O envio foi concluído, mas a Microsoft ainda está revisando o aplicativo. Até a aprovação, a página pode não abrir ou mostrar indisponibilidade.

  • Status atual: aguardando revisão.
  • Nenhuma ação é necessária agora.
  • O botão será liberado depois da publicação oficial.
A versão da Store terá instalação e atualizações pelo canal oficial.

# AltGrid 1.6.7

## Correções

- Impede que uma falha temporária ao carregar o perfil abra indevidamente a configuração de nick para uma conta existente.
- Impede que a verificação opcional de administrador desconecte uma conta comum no Windows.
- Ignora respostas antigas iniciadas antes da renovação do token, preservando a sessão recém-atualizada.
- Evita ações duplicadas ao encerrar uma sessão e reduz conflitos entre o fechamento da conta e a reorganização das telas.
- Corrige o travamento da interface ao fechar uma conta pelo menu da área de contas inativas.

## Interface

- Renova a janela de contas inativas com botão de fechar, contador, ícones dos jogos e lista mais legível.
- Adiciona um botão direto para fechar cada sessão ativa.
- Melhora a navegação e o comportamento dos menus aninhados.

## Plataformas

- Versão alinhada para Windows, Microsoft Store, Android, macOS e Linux.

# AltGrid 1.5.1

## Correções

- Corrige a verificação automática de atualizações no Windows usando um feed estável do próprio AltGrid.
- Corrige a abertura de conversas diretas no chat após a publicação incompleta da estrutura do servidor.
- Melhora o carregamento inicial do catálogo de jogos no site.
- Adiciona uma alternativa visual quando a logo externa de um jogo estiver indisponível.
- Mantém os links de Windows e Android sincronizados com a versão mais recente publicada.
- Adiciona uma versão nativa do AltGrid para Macs com Apple Silicon e processadores Intel.

## Compatibilidade

- Contas, grades, proxies, extensões e demais configurações da versão 1.5.0 são preservados.
- Usuários da 1.5.0 que ainda recebem erro no atualizador devem instalar o Setup 1.5.1 uma única vez. A partir da 1.5.1, as próximas atualizações voltam a funcionar dentro do aplicativo.
- No macOS, a atualização inicial é manual pelo site e preserva os dados locais do aplicativo.

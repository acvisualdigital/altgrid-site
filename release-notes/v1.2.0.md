# AltGrid 1.2.0

Uma atualização grande de estabilidade, controle e usabilidade para Windows e Android.

## Windows

- Proxy exclusivo por conta para usuários Founder, com suporte a HTTP, HTTPS, SOCKS4 e SOCKS5.
- Credenciais de proxy protegidas localmente pela criptografia do Windows.
- Teste de conexão, ativação, remoção e edição da rota sem misturar as sessões.
- Diagnóstico de memória por conta na área de Configurações.
- Perfil de desempenho adaptativo para contas em segundo plano.
- Atualização interna encerra as sessões antes de iniciar o instalador e possui uma etapa de manutenção para remover processos antigos que ainda estejam abertos.

## Windows e Android

- Configurações maiores, mais legíveis e responsivas.
- Chat reabre nas mensagens mais recentes e preserva corretamente a posição do histórico.
- Barra horizontal de contas não volta sozinha ao usar a roda do mouse.
- Melhorias gerais de navegação e estabilidade.

## Android

- Zoom automático e enquadramento móvel normalizado para diferentes aparelhos.
- Sessões continuam rodando em desempenho normal, sem Eco Mode ou economia de RAM.
- Proxy por conta e diagnóstico de memória permanecem exclusivos do Windows nesta versão.

## Instalação

- Windows: use `AltGrid-Setup-1.2.0.exe`. Feche completamente uma versão anterior antes de atualizar.
- Android: use `AltGrid-Android-1.2.0.apk`. Instale sobre o aplicativo oficial já instalado; não use o APK de preview.
